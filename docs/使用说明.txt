========================================
FanControl —— ThinkPad T14s Gen 4 专用智能风扇
(源码 + 捆绑 Python 版, 双击 1-启动风扇控制.bat 即用)
========================================

【前置条件：PawnIO 驱动】
  本程序通过 PawnIO 直接读写 EC，必须先装驱动：
    https://pawnio.eu/     （装完可能需要重启）
  装好后应有 C:\Program Files\PawnIO\PawnIOLib.dll
  没装的话启动脚本会直接告诉你，不会静默失败。

【日常使用（就两步）】
  1. 双击 1-启动风扇控制.bat  →  UAC 弹窗点"是"（自动请求管理员权限）
  2. 托盘出现风扇图标 = 接管成功

【开机自启（推荐直接在托盘菜单里勾选）】
  右键托盘图标 → 勾选/取消「开机自启」
  （计划任务 FanControl-AutoStart, 登录 15 秒后以最高权限启动）
  程序搬家后不用管，启动时会自动修正自启路径

【启动后在哪看】
  托盘风扇图标颜色即状态:
    绿色 = 智能模式（生效中）
    橙色 = 手动模式（生效中）
    红色 = 最强散热（生效中）
    蓝色 = EC 自动（生效中, 备用模式）
    灰色 = 未生效（EC 通信失败, 看日志排查）
  鼠标悬停图标显示: 当前模式 / CPU 温度 / 风扇转速
  右键图标 = 菜单

【托盘菜单（四个模式, 单选）】
  智能模式    按下面的曲线自动调速（推荐, 默认）
  手动模式    子菜单自选档位:
              停转(0) / 1档(2471转) / 2档(2858转) /
              6档(3456~3861转) / 7档(3858转) / 满速(4807转)
              —— 选定后记住, 重启恢复
  最强散热    固定满速 0x40（压温度/跑测试用）
  EC 自动(备用)  交还 BIOS 固件控制
              ★本机实测原生天花板只有 ≈3890 转，压不住满载（28W 满载仍 99°C），
                平时别用；哪天固件修复了再切这个当正常模式
  退出        风扇保持当前状态继续运行（不会交还 EC）

【安全兜底（任何模式都生效）】
  CPU 达到 88°C 时, 无论当前什么模式都临时拉满速 0x40,
  温度降下来后自动回到你选的模式/档位。
  注: 88°C 是 EC 温度（0x78），比核心温度滞后；CPU 侧的功耗墙保护在 95°C。

【智能曲线（可改）】
  40°C 以下停转
  45°C→1档(2471转)   50°C→2档(2858转)
  62°C→6档(3456~3861转)
  84°C→满速 0x40(4807转，需要 20~25 秒才到位)
  降档自带 3°C 滞回, 不会来回抖动
  改法: 记事本打开 config.json, 改 "curve" 后重启程序

  ★只用 0/1/2/6/64 这几档，原因（2026-10-20 全档位实测）：
    0x03=3181  0x04=3186  0x05=3167  —— 三档都挤在 ~3180，没有区分度
    0x07=3858  而 0x06 高温时就有 3861 —— 7 档当不了中间档
    （以前表里的 2029/2362/2600/.../3924/4946 是从别的机型抄来的，
      本机对不上：0x05 比 0x06 还高、0x06 差了 700 转。已全部换成实测值。）

【EC 访问】
  - 温度 0x78 每 5 秒读一次
  - 转速 0x84/0x85 每 6 轮（约 30 秒）读一次
  - 每 30 秒核对一次 0x2F，被固件唤醒流程抢回档位时自动纠正
  - 只在换档时写 0x2F，不写 0x31
    （0x31 是 HUWB/VPON/VRST，不是风扇选择；写它会清 VPON/VRST，转速却不变）

【和旧版的区别】
  - TPFanCtrl2 fork 有两个 bug: 配置里的模式和语言从不生效,
    切换不点"保存全部"就不落盘, 每次开机要手点 Smart
  - 本程序: 启动即按 config.json 的模式运行, 任何切换立即保存
  - 2026-10-20 修正: 删掉每次 EC 操作前写 0x31 的坏习惯、换成本机实测档位表、
    轮询从 2 秒放宽到 5 秒（和 CPU 功耗墙工具共用 EC 总线）

【注意事项】
  1. 双击启动脚本会自动弹 UAC 提权, 点"是"即可
  2. 不要和 TPFanCtrl2.exe / TPFanControl.exe 同时运行（抢 EC）
  3. 日志在同目录 fan_control.log, 出问题先看它（只在换档时写，3MB 自动轮转）
  4. 改曲线: 记事本打开 config.json 改 "curve" 后重启程序

【文件清单】

  fan_control.log        运行日志
  1-启动风扇控制.bat      启动（先检查 PawnIO，再提权）
  2-停止风扇控制.bat      停止（只关风扇工具，不动 CPU 服务）
  FanControl.bat         开机自启用的静默启动器
  runtime\               捆绑 Python 3.13 + pystray/pillow
  src\
    fan_control.py       主程序
    LpcACPIEC.bin        PawnIO 的 EC 模块
    fan.ico              托盘图标
    FanControl.spec      PyInstaller 打包配置（想做成 exe 时用）
