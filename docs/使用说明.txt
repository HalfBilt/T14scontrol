========================================
FanControl —— ThinkPad T14s Gen 4 专用智能风扇
(exe 版, 双击即用, 已内置 EC 访问模块和风扇图标)
========================================

【日常使用（就两步）】
  1. 双击 FanControl.exe  →  UAC 弹窗点"是"（自动请求管理员权限）
  2. 托盘出现风扇图标 = 接管成功

【开机自启（可选）】
  双击 源码\install_autostart.bat  = 注册（登录 15 秒后自动拉起）
  双击 源码\remove_autostart.bat   = 取消

【启动后在哪看】
  托盘风扇图标颜色即状态:
    绿色 = 智能模式（生效中）
    橙色 = 手动模式（生效中）
    红色 = 最强散热（生效中）
    蓝色 = EC 自动（生效中, 备用模式）
    灰色 = 未生效（EC 通信失败, 看日志排查）
  鼠标悬停图标显示: 当前模式 / CPU 温度 / 风扇转速
  右键图标 = 菜单

【托盘菜单（四个模式, 单选）】
  智能模式    按下面的曲线自动调速（推荐, 默认）
  手动模式    子菜单自选档位:
              停转(0) / 1~7 档（1≈2029转 最安静 ... 7≈3924转）
              满速 0x40（≈4950 转）—— 选定后记住, 重启恢复
  最强散热    固定满速 0x40（压温度/跑测试用）
  EC 自动(备用)  交还 BIOS 固件控制（当前工程 EC 曲线是坏的,
              平时别用; 哪天固件修复了再切这个当正常模式）
  退出        风扇保持当前状态继续运行

【安全兜底（任何模式都生效）】
  CPU 达到 88°C 时, 无论当前什么模式都临时拉满速 0x40,
  温度降下来后自动回到你选的模式/档位。

【智能曲线（可改）】
  38°C 以下停转
  40°C→2档(2362转)  48°C→3档  55°C→4档  62°C→5档(3185转)
  68°C→6档  74°C→7档(3924转)  84°C→64档(真满速4946转)
  降档自带 3°C 滞回, 不会来回抖动
  改法: 记事本打开 config.json, 改 "curve" 后重启程序
  失效保护: CPU 达到 88°C 无条件拉满速

【和旧版的区别 / 为什么换它】
  - TPFanCtrl2 fork 有两个 bug: 配置里的模式和语言从不生效,
    切换不点"保存全部"就不落盘, 每次开机要手点 Smart
  - 本程序: 启动即按 config.json 的模式运行, 任何切换立即保存
  - 去掉了没用的功能: PID/键盘背光/多语言/双风扇/EC自动等

【注意事项】
  1. 双击 exe 会自动弹 UAC 提权, 点"是"即可
  2. 不要和 TPFanCtrl2.exe / TPFanControl.exe 同时运行（抢 EC）
  3. 日志在同目录 fan_control.log, 出问题先看它
  4. 改曲线: 记事本打开 config.json 改 "curve" 后重启程序
  5. 首次运行如被 SmartScreen 拦: 点"更多信息"→"仍要运行"
     （自打包 exe 无微软签名, 属正常现象, 程序无网络行为）

【文件清单】
  FanControl.exe        主程序（双击即用, 已内置 EC 模块和图标）
  config.json           配置（模式/曲线/档位, 自动生成和保存）
  fan_control.log       运行日志
  源码\                 源码与工具（平时不用动）
    fan_control.py        Python 源码
    FanControl.spec       PyInstaller 打包配置
    重新打包.bat          改完源码后双击重新生成 exe
    install_autostart.bat 注册开机自启（指向 exe）
    remove_autostart.bat  取消开机自启
    LpcACPIEC.bin / fan.ico / start_fancontrol.bat
